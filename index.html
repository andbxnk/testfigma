บทเรียนที่ 1: UX Process & Real-World Case Studies

กระบวนการคิดวิเคราะห์ UX, Pain Point และตัวอย่างจริงในอุตสาหกรรม

เรียนรู้ขั้นตอนการสกัดปัญหา (Pain Point) จากเคสจริง เช่น แอปสั่งอาหาร แอปธนาคาร และการวาง User Flow พร้อมตัวอย่าง Figma Components

กรณีศึกษาตัวอย่างจริง 1: แอปสั่งอาหาร (Food Delivery)

การสกัด Pain Point -> HMW -> โซลูชันฟีเจอร์ใหม่

Real-world Case Study
1. PAIN POINT ที่เจอจาก RESEARCH

ผู้ใช้บ่นว่า "สั่งอาหารผิดเมนูแล้วหากดปุ่มยกเลิกออเดอร์ไม่เจอ" หรือ "คนแพ้อาหารทะเลค้นหาอาหารปลอดภัยยากมาก" ทำให้กดยกเลิกไม่ทันและเสียเงินฟรี

2. การสกัดเป็น HMW STATEMENT

HMW 1: "เราจะทำอย่างไรให้ผู้ใช้ยกเลิกคำสั่งซื้อได้ง่ายภายใน 60 วินาทีแรก?"
HMW 2: "เราจะทำอย่างไรให้ระบบช่วยกรองวัตถุดิบที่ผู้ใช้แพ้ออกให้อัตโนมัติ?"

3. SOLUTION & FEATURE DESIGN

Feature 1: ปุ่ม "Undo / Cancel Order" นับถอยหลัง 60 วินาทีบนหน้าติดตามออเดอร์
Feature 2: ตัวกรอง "Allergy Filter" บันทึกประวัติอาหารแพ้ใน Profile

บทเรียนที่ 2: Figma Core Tools & Symbols Summary

สรุปสัญลักษณ์ เครื่องมือ คีย์บอร์ดลัด และจุดหลอกข้อสอบ

รวมสัญลักษณ์ทุกเครื่องมือใน Figma (❖, ◇, ❖❖, #, ||, 📐, 🎨) พร้อมตารางเปรียบเทียบเชิงลึกเพื่อตอบข้อสอบได้อย่างถูกต้อง

❖ Main Component vs ◇ Instance Component

คุณสมบัติ Main Component (❖) Instance Component (◇)
สัญลักษณ์ ❖ เพชรทึบ 4 เม็ด ◇ เพชรโปร่ง 1 เม็ด
บทบาท ต้นแบบแม่พิมพ์หลัก ชิ้นงานลูกที่คัดลอกออกมาใช้งาน
ผลของการแก้ไข แก้ที่นี่ เปลี่ยนตามทั้งโปรเจกต์ แก้เฉพาะตัวได้ (Override) เช่น เปลี่ยนสี/ข้อความ
จุดหลอกข้อสอบ ห้ามใช้ Main ไปวางกระจายทั่วหน้าจอ ให้ใช้ Instance แทน ไม่สามารถย้ายโครงสร้าง Layout ข้างในได้ ถ้าไม่แก้แม่

# Frame vs [ ] Group

คุณสมบัติ Frame (# / F) Group (Cmd+G)
ขอบเขต (Bounds) มีขอบเขตอิสระแยกจากวัตถุภายใน ขนาดขึ้นอยู่กับวัตถุข้างในรวมกันเท่านั้น
Clip Content ทำได้ (ซ่อนวัตถุที่ล้นขอบ) ทำไม่ได้
Constraints รองรับการกำหนดพิกัดตรึงยึด ยืดหดตามสเกลสัดส่วนตลอดเวลา
Auto Layout เปิดใช้งาน Auto Layout ได้ เมื่อแปลงเป็น Auto Layout จะถูกเปลี่ยนเป็น Frame อัตโนมัติ

ตารางสรุป Resizing ใน Auto Layout: Hug Content vs Fill Container vs Fixed Width/Height

Hug Content หดรัดตามเนื้อหา

ขนาดของ Frame แม่ จะขยายหรือหดตามขนาดวัตถุหรือข้อความที่อยู่ข้างใน + ค่า Padding เหมาะสำหรับทำ ปุ่มกด (Buttons) หรือ Badges

Fill Container ยืดเต็มพื้นที่

วัตถุลูกข้างในจะยืดขยายตามขนาดความกว้าง/ความสูงของ Frame แม่ตลอดเวลา เหมาะสำหรับทำ การ์ด Responsive หรือข้อความบรรทัดยาว

Fixed Width / Height ล็อกขนาดคงที่

กำหนดขนาดพิกเซลคงที่ ไม่ยืดและไม่หดตามวัตถุข้างในหรือ Frame แม่ เหมาะสำหรับทำ ไอคอนขนาดคงที่ (เช่น 24x24 px) หรือ Avatar
